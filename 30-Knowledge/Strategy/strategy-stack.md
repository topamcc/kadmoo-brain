# Strategy Stack — שכבות אסטרטגיה

המודלים אינם מתחרים: מרכיבים **Stack** — כל שכבה עונה על שאלה אחרת.

## 1. פירמידת המודעות והנאמנות

**שאלה:** באיזה שלב הקהל נמצא?

- לא מודע למותג / מכיר תחום אך לא עסק / מכיר ואינו מעדיף
- שוקל / קרוב להחלטה / לקוח / רדום / נאמן

המסר והזווית משתנים לפי השלב — לא מדברים לכולם באותה שפה.

## 2. חד · מבודל · רלוונטי

**שאלה:** האם המסר ראוי לצאת לפרסום?

- **חד** — ברור בתוך שניות
- **מבודל** — מתחרה לא יכול לפרסם בדיוק אותו דבר
- **רלוונטי** — נוגע בצורך אמיתי של הקהל

אם אחד חסר — לא מקדמים קונספט.

## 3. WHY → WHAT → HOW

**שאלה:** מאיזו זווית מספרים את הסיפור?

- **WHY** — למה זה חשוב / למה עכשיו
- **WHAT** — מה מציעים / מה משתנה
- **HOW** — איך זה עובד / מה לעשות

ניתן לפתוח מכל נקודה, אבל חייבים עקביות לאורך המודעה.

## 4. צורך · תועלת · כאב · שאיפה · הוכחה

**שאלה:** מה מניע את האדם לפעול?

בחרו מנגנון שכנוע מרכזי אחד (או שניים משלימים):

| מניע | תפקיד |
|------|--------|
| צורך | למה בכלל |
| תועלת | מה מרוויחים |
| כאב | מה כואב עכשיו |
| שאיפה | לאן רוצים להגיע |
| הוכחה | למה להאמין |

## 5. אנלוגיה · מטאפורה · השוואה · הגזמה

**שאלה:** איך הופכים מסר לקריאייטיב שתופס?

- אנלוגיה / מטאפורה — רעיון מוכר שמסביר את היתרון
- השוואה — מול חלופה, מחיר, או מצב קודם
- הגזמה / קנה־מידה — עצירת גלילה בלי לאבד אמינות

המנגנון הוויזואלי והקופי חייבים לשרת את אותה שכבת Stack שנבחרה למעלה.

# Creative OS — שלבי Pipeline (0–12)

תהליך קבוע לכל יצירת קריאייטיב, ללא קשר לענף או פורמט.

| שלב | שם | תמצית |
|-----|-----|--------|
| **0** | Client DNA | תיק לקוח מתמשך: מוצרים, קהלים, בידול, הוכחות, טון, מותג, אסורים, מתחרים, ביצועים ופידבק. |
| **1** | זיהוי טריגר | בקשת לקוח, ירידה בביצועים, עייפות קריאייטיב, מבצע, RTM, יוזמת מנהלת — תמיד עם הצעת פעולה. |
| **2** | תפקיד הקמפיין | עבודה אחת למודעה (מודעות / בעיה / פתרון / העדפה / ליד / מכירה וכו׳). ניסוח: לגרום ל־[קהל] להבין/להרגיש/לעשות X כי החסם הוא Y. |
| **3** | Strategy Stack | יעד עסקי → מצב קהל → חסם → מנגנון שכנוע → מבנה סיפור. תוצר: Creative Strategy Card קצרה. |
| **4** | זיקוק מסר | מסר ראשי · משני · סיבת אמונה · CTA. היררכיית קשב (למשל 60/20/20) לפי הצורך. |
| **5** | מנוע רעיונות | מסר + אמת אנושית + רגש + מנגנון ויזואלי = קונספט. רגש משרת מכירה, לא גימיק. |
| **6** | טריטוריות | 20–40 כיוונים → 5 טריטוריות → 3 קונספטים → בחירה לבדיקה/הפקה. |
| **7** | מבחן קונספט | בהירות, רלוונטיות, בידול, stopping power, חיבור למוצר, אמינות, מותג, פלטפורמה, הפקה. מבחני 3 שניות / הסרת לוגו / תיאור במשפט. |
| **8** | קופי + ארט במקביל | הוקים וכותרות לצד קומפוזיציה, סגנון, טיפוגרפיה — רעיון אחד משותף. |
| **9** | מסלול הפקה | סטילס / קרוסלה / וידאו (+ עקביות AI אם רלוונטי). |
| **10** | בקרת איכות | אסטרטגיה, קופי, עיצוב, מותג, עובדות, רגולציה, פורמט, מובייל, CTA. |
| **11** | הצגה ללקוח | מיסוג ההחלטה לפי מטרה; פידבק מובנה (עובדות / הבטחה / מגבלה / העדפה אישית). |
| **12** | הפצה ולמידה | מדדים + סיבת הצלחה/כישלון → Creative DNA מתעדכן ללקוח. |

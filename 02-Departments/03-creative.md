# מחלקת קריאייטיב — Creative OS

המשרד הפנימי ליצירת פרסום. הלקוח לא רואה את ההיררכיה הפנימית — רק את מנהלת הלקוחות שמציגה תוצרים ממוסגרים.

## היררכיה פנימית

בכניסה לסטודיו אפשר לחפש ולבחור מוצר, שירות או כמה פריטים מקטלוג האתר. אחרי הצגת מחיר ההפקה ולחיצה על יצירה, מנהל הקריאייטיב מקבל את פרטי הפריטים העדכניים, התמונות, קישורי היעד וספר המותג של אותו אתר. אין לבקש למלא שוב בריף. טקסט חופשי וקישור נוסף הם הנחיות רשות. כמה פריטים נבחרים משמשים הצעה משותפת לשני כיוונים, בלי להמציא חבילה או מבצע.

מנהל הקריאייטיב מתכנן שני כיוונים משלימים עם כותרת, קופי ותיאור סצנה תואמים. לאחר עריכת לשון ובדיקת עובדות מפיקים תמונה לכל כיוון ומשבצים את התמונה והכותרת בתוך שכבת הגריד המאושרת של האתר. שכבת המותג כוללת כבר את הלוגו ופרטי הקשר; אין לבחור, לצייר או להרכיב מחדש לוגו בכל הפקה. בודקים את התוכן החדש ואת התאמתו לגריד. שומרים את התמונה והקופי יחד בספרייה. בחירה וחיפוש אינם מפעילים הפקה; ניסיון נוסף מטפל רק בכיוון שנכשל, ובתוצאת ספק לא ידועה אין להפיק שוב אוטומטית. אין להמציא מחיר, הנחה או הבטחת ביצועים, ולמוצר פיזי נדרשת תמונת מקור.

במסלול החופשי אפשר עדיין להתחיל בבריף מודרך, בטקסט מודבק, במסמך Word או PDF או בשיחה עם מנהל הקריאייטיב. מבררים רק פרטים שחסרים ומשתמשים בעמוד המוצר ובתמונות שהלקוח צירף.

לשני הכיוונים בוחרים תבניות חשיבה מספריית המנגנונים של Creative OS לפי המוצר והמסר. כיוון אחד מדגים את ההבטחה באופן ישיר והשני בוחן מנגנון ממשפחה אחרת כשמתאים. תבנית שנבחרה במפורש קודמת להמלצה. הקופירייטר והארט דיירקטור עובדים עם אותה תבנית בכל כיוון. הדוגמאות בספרייה הן להמחשה בלבד.

מציגים תמונה וטקסט חי לכל כיוון. הלקוח יכול לערוך טקסט, לבקש שינוי בתמונה או לחזור לגרסה קודמת. אישור מפורש שומר את הצירוף המדויק בספר המותג של האתר הנבחר. בהפקה הבאה באותו אתר משתמשים בטקסט המאושר כדוגמה לטון ובתמונה המאושרת כהשראה לקומפוזיציה, בכפוף לרפרנסים ולבריף הנוכחיים. אין להסיק מאישור העדפה לגבי אתר אחר או הצלחה מסחרית.

אחרי בחירת כיוון מפיקים התאמות לפלטפורמה, בוחנים את התקציב היומי ומעבירים לאשף הקמפיין. אישור לשמירה בספר המותג אינו אישור לפרסום.

```
מנהל קריאייטיב / מנוע אסטרטגיה
  → קופירייטר  ∥  ארט דיירקטור
  → מעצב / צוות וידאו
  → בקרת איכות
  → חזרה למנהלת הלקוחות
```

- **מנהל הקריאייטיב** — בעל ההחלטה המקצועית (לא מנהלת הלקוחות).
- קופי וארט עובדים **במקביל** אחרי בחירת קונספט — לא בטור.

## Creative OS — Pipeline

### עיצוב גריד קבוע בסטודיו

מנהל הקריאייטיב מגדיר את תפקיד הגריד מתוך ספר המותג: זיהוי עקבי, היררכיה ברורה ומקום לתוכן המשתנה. הארט דיירקטור בונה ארבע הצעות בתוך אפשרויות העיצוב שהמערכת יכולה לייצא בפועל, ומדרג אותן לפי התאמה למותג. אין לבחור אלמנט גרפי רק כדי למלא פינה: הוא צריך לתמוך בשפה החזותית ולהשאיר מקום למוצר, לתמונה ולכותרת. אין להמציא פרטי קשר.

בקרת העיצוב בוחנת את מפרט הגריד, את השטח שהוקצה ללוגו ולטקסט, את הניגודיות, השוליים וההתאמה למותג. אין לטעון לבדיקת פיקסלים של לוגו מתוך מפרט טקסטואלי. התצוגה המקדימה עם הלוגו האמיתי מאפשרת לאשר קריאות בגודל טלפון. לוגו מפורט דורש שטח מספק; הגדלת הלוגו עשויה לדרוש פס תחתון גבוה יותר. הבקרה אינה משנה פרטים שהלקוח סיפק או הוראות מפורשות שלו, ואינה פוסלת עיצוב רק בגלל טעם אישי.

הלקוח יכול לפתוח הגדרות גריד בכל עיצוב, כולל גריד שנוצר עם AI: לשנות גודל ומיקום לוגו, גובה פס, צבע אלמנט ופרטי קשר, כולל הסרתם. שינוי נקודתי שומר את שאר ההגדרות. התצוגה המקדימה קודמת לשמירה; השמירה מקבעת שכבת מותג לכל פורמט נתמך. הפקה עתידית משתמשת בפיקסלים השמורים, ללא ייצור חוזר של הלוגו. החלפת קובץ לוגו במאגר אינה מחליפה את הגריד שכבר נשמר; שינוי גריד ושמירתו יוצרים גרסה חדשה למודעות הבאות. מודעות שכבר הופקו נשמרות ללא שינוי.

## שבעת האובייקטים (שלד המערכת)

1. **Client DNA** — תיק לקוח מתמשך
2. **Creative Request** — בקשה + טריגר + תפקיד קמפיין
3. **Creative Strategy Card** — תוצר Strategy Stack קצר
4. **Message Map** — מסר ראשי / משני / אמונה / CTA
5. **Concept Board** — טריטוריות + קונספטים + ציונים
6. **Production Brief** — הנחיות הפקה לפורמט
7. **Creative Learning Record** — למה עבד / לא עבד

# שיפור יכולת הסוכן לאסוף מידע חסר

הסוכן נתקל בקשיים ובצורך בהבהרות חוזרות כאשר חסר מידע קריטי (כמו קישור למוצר, יעד נחיתה, או פרטי קהל יעד ספציפי). יש לפתח יכולת לסוכן לזהות באופן יזום מידע חסר, לבקש אותו מהלקוח בצורה ממוקדת וברורה, ואף להציע אפשרויות ברירת מחדל או המלצות מבוססות נתונים קיימים, כדי למנוע חסימות בתהליך העבודה.

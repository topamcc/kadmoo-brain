# סטנדרטיזציה באיסוף פרטי מוצר וקהל יעד

הסוכן מתקשה לעיתים לאתר פרטי מוצר ספציפיים או מידע מדויק על קהל היעד. יש להטמיע תהליך קליטה מובנה לקמפיינים חדשים, שיחייב את הלקוח לספק מראש את כל הפרטים הרלוונטיים (קישור למוצר, תכונות, מחיר, קהל יעד מפורט).

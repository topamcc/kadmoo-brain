# צמצום העברות משימות ל'סוכן מומחה'

מספר משימות מועברות ל'סוכן מומחה' כאשר הסוכן הרגיל אינו מצליח להשלים אותן, לעיתים קרובות עקב מורכבות, חסימה טכנית או צורך בהבהרות. יש לנתח את הסיבות השכיחות להעברות אלו ולשפר את יכולות הסוכן הראשי (באמצעות הרחבת יכולות, הדרכה או כלים נוספים) כדי שיוכל לטפל ביותר תרחישים באופן עצמאי.

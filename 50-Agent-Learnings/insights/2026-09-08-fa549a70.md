# איסוף מידע פרואקטיבי להקמת קמפיינים

הסוכן נדרש לעיתים קרובות להבהרות או למידע ספציפי מהמשתמש (כגון קהל יעד, פרטי מוצר, הגדרות ספציפיות, קישורים, קבצים) במהלך הקמת קמפיינים, מה שמוביל להתכתבויות חוזרות ועיכובים. על הסוכן ליישם שלב איסוף מידע מובנה יותר בתחילת כל קמפיין חדש, ולשאול את כל השאלות הקריטיות מראש כדי למזער איטרציות ועיכובים.

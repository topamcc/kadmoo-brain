# ניהול ציפיות והעברת משימות

במקרים רבים, הסוכן מדווח על אי-יכולת לבצע משימה ומעביר אותה ל'סוכן מומחה'. יש לבחון את הפערים ביכולות הסוכן הנוכחי, להרחיב את סמכויותיו/גישתו לכלים, או לחלופין, לשפר את ניהול הציפיות מול הלקוח ולהסביר מראש אילו משימות דורשות התערבות אנושית או סוכן בעל יכולות מתקדמות יותר, כדי למנוע תסכול.

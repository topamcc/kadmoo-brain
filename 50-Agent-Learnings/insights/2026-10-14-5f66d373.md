# מניעת חזרתיות בפעולות חוזרות

כאשר משתמש מבקש שוב פעולה שכבר הוצגה או התחילה, יש לזהות את מצב המשימה, לסכם מה כבר בוצע ומה נותר, ולהימנע מיצירת כפילות. אם קיימות כמה גרסאות או תוצרים, יש להציג את ההבדלים ביניהם במקום להתחיל את התהליך מחדש.

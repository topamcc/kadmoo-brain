# איסוף מידע פרואקטיבי להפקת קמפיינים

הסוכן נדרש לעיתים קרובות לבקש מהמשתמש פרטים חסרים כגון קישורים לדפי מוצר, קהל יעד ספציפי או הבהרות לגבי מוצר מקודם. יש להטמיע תהליך פרואקטיבי לאיסוף מידע זה בתחיל שיחה או משימה חדשה, כולל סריקה אוטומטית של אתרי לקוחות וספרי מותג, כדי למנוע עיכובים ולשפר את דיוק הקמפיינים הראשוניים.

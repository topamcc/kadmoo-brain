# איסוף מידע מקיף לקמפיינים ממומנים

בעת יצירת קמפיין ממומן חדש, יש לאסוף באופן שיטתי את כל הפרטים הנדרשים מראש: מוצר/שירות ספציפי לקידום (כולל קישור לדף מוצר), קהל יעד מפורט, יעד הקמפיין (לידים, מכירות, מודעות), תקציב רצוי (יומי/חודשי) ויעד נחיתה. זה ימנע חילופי מידע חוזרים ויזרז את תהליך ההקמה.

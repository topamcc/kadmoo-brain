# זיהוי והתמודדות עם חסמים טכניים

הסוכן נתקל שוב ושוב במגבלות טכניות (חיבורי חשבונות, שליפת נתונים, תקלות מערכת) המונעות ביצוע משימות או מתן מידע. במקרים אלו, יש להבהיר למשתמש את החסם הטכני, להציע פתרונות (כגון חיבור חשבונות), ובמידת הצורך, להסלים את הטיפול לגורם מומחה או להפנות לתמיכה טכנית באופן יזום וברור.

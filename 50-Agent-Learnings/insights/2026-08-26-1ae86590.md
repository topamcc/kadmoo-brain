# שיפור איסוף מידע והבהרות מול לקוחות

הסוכן נדרש לעיתים קרובות לבקש הבהרות לגבי פרטי מוצר, קהל יעד ספציפי, עמודי נחיתה או מיקוד קמפיין. יש לפתח מנגנונים שיאפשרו לסוכן לאסוף מידע מקיף ומדויק יותר בתחילת השיחה או המשימה, או להשתמש במודל שפה חזק יותר שיכול להסיק פרטים חסרים מתוך הקשר רחב יותר.

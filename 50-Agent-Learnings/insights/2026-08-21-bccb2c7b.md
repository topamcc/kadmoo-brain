# ייעול תהליך איסוף נתונים לקמפיינים חדשים

הסוכן נדרש לעיתים קרובות לבקש פרטים נוספים מהמשתמש לאחר בקשה ראשונית לקמפיין (לדוגמה: קישור לדף מוצר, מיקוד קהל יעד ספציפי, הבהרת מוצר מקודם, יעד נחיתה למודעה). יש לפתח תהליך תשאול מובנה ויזום יותר בתחילת כל בקשת קמפיין, שיאסוף את כל הפרטים החיוניים (מוצר/שירות, קהל יעד, תקציב, פלטפורמה, מטרות, נכסים קיימים) בפעם אחת, כדי למנוע סבבי שיחות מיותרים ולזרז את השקת הקמפיין.

# איסוף מידע פרואקטיבי על מותג ומוצר

הסוכן נדרש לעיתים קרובות לבקש הבהרות לגבי פרטי מוצר, קהל יעד ספציפי או דף נחיתה. יש לפתח תהליך איסוף מידע פרואקטיבי בתחילת כל פרויקט (קמפיין/תוכן), אולי באמצעות שאלון מובנה או סריקה אוטומטית מעמיקה יותר של אתר הלקוח ו'ספר המותג' שלו, כדי למנוע צורך בבקשות חוזרות.

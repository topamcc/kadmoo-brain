# Agent Learnings

תיקייה ל־**write-back** מהסוכן: תובנות, דפוסי הצלחה/כישלון, והערות תפעוליות שנלמדו בזמן ריצה.

## איך זה עובד

1. הסוכן (או תהליך סנכרון) כותב לכאן מסמכים חדשים — בדרך כלל כ־`draft` / למידה גולמית.
2. אדם סוקר, מחדד, ומשלב לעקרון יציב.
3. **קידום ל־Playbook:** מעבירים את התוכן (או גרסה מזוקקת) ל־`20-Playbook/` עם:
   - `kadmoo_type: playbook`
   - `status: approved`
4. רק אחרי `approved` + push — הלמידה נכנסת לסנכרון לסוכן.

אין לסנכרן ישירות מתיקייה זו בלי קידום מפורש ל־Playbook/Knowledge מאושר.

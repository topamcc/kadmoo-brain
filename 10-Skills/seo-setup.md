# הגדרות SEO וחיבורים

מחלקה: [[05-seo-geo]] · ידע: [[onboarding-connections]]

1. אתר חדש → create_site (כרטיס אישור)
2. check_seo_setup + get_site_integrations_status — צ׳קליסט מלא
3. חיבור חסר → get_connect_links (כרטיס לכל החיבורים: GA, SC, Ads, Meta, Social, Clarity, GBP, WP/Wix/Shopify)
4. וורדפרס: check_site_plugin_status → verify_site_connection
5. מה שאפשר מיד: suggest_keywords + run_site_audit (באישור)
6. מה שלא — create_ticket בלי להפנות ל"תמיכה אנושית"
